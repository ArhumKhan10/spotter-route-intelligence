The app opens with an explicitly labeled example trip. **Find safest route**
requests live OSRM routing and Open-Meteo weather. Try different cities, load
weights, and checkpoint intervals; inspect route comparison and checkpoints,
then explore the 48-hour corridor forecast.

The README explains setup, exact boundary interpretations, risk-mile estimates,
ranking priorities, and the public driving profile’s truck-compliance limits.
Automated checks and deployment verification are described in
[VERIFICATION.md](VERIFICATION.md).
